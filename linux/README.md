# Linux Lab

Hands-on Linux system administration and troubleshooting practice.

## System Administration

- User and group management
- File ownership and permissions
- Sudo and group-based access
- Systemd services
- SSH service management
- Disk and filesystem investigation

## Troubleshooting

Practical troubleshooting scenarios covering:

- CPU and memory usage
- Disk space investigation
- Network connectivity and DNS
- Services and listening ports
- File and service permissions
- SSH connectivity

## Automation

- Creating compressed backups with `tar`
- Date-based backup filenames
- Scheduling tasks with `cron`
- Testing and verifying automated backups

## Main Tools

`top` · `ps` · `free` · `uptime` · `df` · `du` · `ip` · `ping` · `ss` · `systemctl` · `journalctl` · `tar` · `crontab` · `ssh`

## Goal

The goal of this lab is to build practical Linux system administration skills through hands-on scenarios and troubleshooting exercises.
